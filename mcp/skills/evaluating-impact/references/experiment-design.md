# 实验设计与效果评估方法卡

三张方法卡：A/B 实验检验、DID 双重差分、ROI 与业务行动。按数据条件选最轻量且可信的方法——有随机对照优先 AB；无随机但有对照+前后数据用 DID；只有收益成本做 ROI（不证明因果）。方法卡配合 `impact` 工具的对应 `analysis_type` 使用。

## A/B 实验检验（`ab_rate` / `ab_mean` / `sample_size_rate`）

### 假设与指标设定

- 主指标**事先定义**：一个实验只有一个主指标（点击率、转化率、留存、北极星），事后挑指标 = 多重比较作弊。
- 指标分层：**核心指标**（决策依据）、**护栏指标**（留存、投诉、退款、卸载、性能、收入质量——变差即一票否决）、**诊断指标**（理解为什么有效/无效，不做决策依据）。
- 假设方向、观察窗口、归因窗口（动作到转化的最长间隔）都在实验前锁定。

### 样本量与 MDE

- 实验前用 `sample_size_rate` 估样本量：给 `baseline_rate`、`minimum_detectable_effect`（MDE，业务能接受的最小绝对提升）、`alpha`（默认 0.05）、`power`（默认 0.8）。
- MDE 越小、基率越接近 0.5，所需样本越大；估出的是**每组**样本量，还需除以预计触达率、乘以完整周期数（覆盖周内周期性，至少一个完整周期）。
- 样本不够就先别开实验——开了也只能得到"不显著"，无法区分"没效果"和"检不出"。

### 分析前检查清单

- 随机分流：两组用户特征分布应一致（可抽样对比）。
- **SRM（样本比例失衡校验）**：实际两组 n 比例 vs 分流配置比例；明显偏离（如 1:1 分流得到 >2% 偏差）说明分流/曝光日志被污染，全部结论作废。
- 跨组污染：账号多端、共享设备、网络代理导致用户实际两组都体验。
- 提前停止风险：盯盘看到显著就停会大幅推高假阳性；要么事先定死时长，要么用序贯检验。
- 观察窗口完整、无补数延迟。

### 显著性与置信区间解读陷阱

- p 值是"零假设下看到该数据的概率"，不是"效果为真的概率"；巨大样本下微小效果也显著——**统计显著≠业务显著**，上线决策看 `absolute_lift` 的置信区间下界是否达到业务最小可接受效果。
- 不显著≠没效果：先回看样本量/MDE/power，可能根本检不出真实量级。
- 多重比较：同时检验 k 个指标，期望 k×α 个假阳性；核心指标显著才作数，其余只做参考。
- `ab_mean` 用正态近似，小样本/重尾/强偏态（客单价、时长常见）需专项检验；两组聚合口径必须一致（都按用户或都按订单）。
- achieved power 不作默认输出：它易被误读成"实验质量证明"，决策看预设 power、MDE、效果量与 CI。
- CUPED 等方差缩减技术 `impact` 不支持，高价值实验需用户级明细专项分析。

## DID 双重差分（`did`）

### 原理

四格结构：`did_effect = (treatment_after - treatment_before) - (control_after - control_before)`。直觉：处理组自己涨了多少不够，要扣掉对照组同期自然涨跌，剩下的才接近干预增量。

### 平行趋势假设（DID 的命门）

- 核心假设：**若无干预，处理组走势与对照组平行**。这不是 `did_effect` 算出来的，要单独验证。
- 事件研究检验：取干预前多期数据，逐期算"处理组-对照组"差值；干预前各期差值稳定（无趋势、无显著非零）才支持平行趋势。
- 只有一个前置周期无法判断趋势，结论强度降为"仅方向性"；干预前已分叉则不要把 DID 写成"较可信因果"。

### 对照组选择

- 业务结构相似：渠道、人群构成、城市等级、历史规模相近。
- 常见构造：相邻城市/区域、分批上线的后批用户、策略未触达的相近人群。
- 检查同期干扰：只影响某一组的活动、投放、价格、库存、口径变更会直接进 `did_effect`；用户迁移/污染同样会。
- 干预时间要清楚：提前泄露（预告期用户已改变行为）或滞后生效都会污染前后窗口；前后窗口须同天数、同完整度、同过滤条件。
- `impact` 只支持四格聚合 DID；面板回归、分批干预（staggered DID）、动态效应需专项分析。

## ROI 与业务行动（`roi`）

### 归因口径（ROI 最容易出错的地方）

- `roi = (benefit - cost) / cost`；**必须说清 benefit 是总收入还是因果增量**。
- 收入口径 ROI 常高估：混入自然增长（本来就会买的人）和蚕食（券只是把原订单搬到活动期）。真正的增量口径来自 AB/DID 估计的 lift × 规模。
- 高补贴、高退款、低毛利场景必须看毛利口径：传 `gross_margin_rate` 得 `margin_adjusted_roi`，或已有估算好的增量毛利直接传 `incremental_margin` 得 `incremental_margin_roi`。
- 成本要全：补贴 + 投放 + 库存/履约 + 人力 + 机会成本；收益要扣退款。

### 业务动作评估（ROI 之外还要看）

- 前后变化与可比周期（同比/环比/同星期/同活动节奏）。
- 漏斗节点：曝光→触达→点击→转化→支付→复购，变化发生在哪一环。
- 分层效果：渠道/人群/地区/版本是否一致（整体为正可能掩盖某层严重为负）。
- 护栏指标：留存、投诉、退款、卸载、性能、收入质量。

### 续投/扩量决策框架

- 增量毛利口径 ROI>0 且护栏稳定 → 可续投；扩量时警惕边际递减（最优人群先吃掉，规模翻倍效果通常不翻倍）。
- 收入口径 ROI>0 但毛利口径<0 → 停止或重构方案。
- 短期 ROI 为正但护栏（留存/投诉）变差 → 不加码，先补长期观察。
- 只有前后对比没有对照 → 结论写方向性；要强证据需补随机实验或 DID。
- 常见动作要点：发券看核销率/蚕食/价格敏感；Push 看退订卸载与疲劳；大促投放看 CAC、回本周期、库存与获客质量。

# 异动归因输出校验

## 必须包含

- 指标名称、口径、当前窗口、基准窗口。
- 当前值、基准值、绝对变化、相对变化。
- 异动是否成立，以及判断依据。
- 数据质量和口径检查结论。
- Top 驱动因素、贡献量 `Vi`、贡献率 `Ci = Vi / ΔY`、相对贡献 `Ri = Vi / Y0` 或影响规模。
- 已验证证据和未解释残差。
- 置信度标签和下一步行动建议。

## 表达边界

- 不要把相关性写成因果。
- 不要把“贡献最大”写成“根本原因”，除非有独立证据验证。
- 不要忽略数据延迟、口径变更、样本量过小。
- 不要只报告百分比，必须给出基数或影响量。
- 不要混淆贡献率和相对贡献：贡献率解释总变化的分摊，相对贡献解释分项让大盘较基准变化了多少。
- 不要用过多维度下钻制造看似精确的结论。

## 推荐结论格式

```text
一句话结论：
<指标> 的 <上升/下降> 主要由 <因素> 驱动，该因素解释了 <贡献比例/影响量>。

关键证据：
1. <指标复现与异动判断>
2. <贡献度或分解结果>
3. <业务事件/系统变更/外部因素验证>

置信度：
<已验证/较可能/待验证>，因为 <证据链说明>。

建议：
<业务动作、数据补充、继续验证或监控方案>。
```

## 适合展示的图表

- 趋势对比图：展示当前值、基准值、异常窗口。
- 瀑布图：展示各因素对总变化的贡献。
- 帕累托图：展示 Top 贡献和累计贡献。
- 漏斗图：展示链路节点变化。
- 分组柱状图：展示分组当前值、基准值和贡献。

数值图表应使用 `visualizing-data`，不要用 AI 生图。

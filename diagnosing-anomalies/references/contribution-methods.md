# 贡献度拆解方法

本文件用于把异动解释量化成“谁让总体变化了多少”。优先输出贡献量、贡献率、相对贡献和未解释残差；不要只给定性原因。

拿到结构化聚合数据后，可优先使用 `../scripts/contribution.py` 做标准计算。输入输出规范见 `contribution-calculator.md`。

## 方法选择

| 场景 | 使用方法 | 主要输出 | 注意事项 |
| --- | --- | --- | --- |
| 总量由分项相加 | Delta 法 / 加法贡献 | 贡献量、贡献率、相对贡献 | 贡献可求和，适合帕累托排序 |
| 指标由多个因子相乘 | LMDI / log 拆解 | 因子对数贡献率、近似影响量 | 因子必须为正，零值需特殊处理 |
| 多因素共同作用 | Shapley | 平均边际贡献 | 需要组合实验、模型估计或可靠反事实 |
| 比率指标 | 组间组内拆解 | 组内贡献、结构贡献、交叉项 | 必须同时看分子、分母、结构变化 |
| 漏斗链路 | 链式拆解 | 节点转化贡献、瓶颈节点 | 先找关键断点，再做维度下钻 |
| 非线性公式 | 泰勒展开 / 定基代替 | 边际贡献或替换贡献 | 可能有残差，需显式说明 |

## 统一符号

```text
0 = 基准期
1 = 当前期
Y0, Y1 = 总体指标基准值、当前值
ΔY = Y1 - Y0
g = ΔY / Y0，总体相对变化率
Xi0, Xi1 = 第 i 个分项或因子的基准值、当前值
ΔXi = Xi1 - Xi0
Vi = 第 i 项贡献量，单位与 Y 一致
Ci = 第 i 项贡献率，回答“解释了总变化的多少”
Ri = 第 i 项相对贡献，回答“让总体相对基准变化了多少”
```

输出时区分三个口径：

- **贡献量 `Vi`**：分项带来的绝对变化，单位与指标一致。
- **贡献率 `Ci = Vi / ΔY`**：分项解释了总变化的多少；可超过 100% 或为负，因为存在抵消项。
- **相对贡献 `Ri = Vi / Y0`**：分项让总体相对基准变化了多少，适合回答“带来几个百分点/增长了百分之多少”。

## 加法型指标：Delta 法

适用于收入、订单数、用户数、工单数等可按维度相加的指标。

### 基本形式

若：

```text
Y = Σ Xi
```

则：

```text
ΔY = Y1 - Y0 = Σ(Xi1 - Xi0) = ΣΔXi
Vi = ΔXi
Ci = Vi / ΔY = ΔXi / ΔY
Ri = Vi / Y0 = ΔXi / Y0
```

`Ci` 用于解释“总变化由谁贡献”，`Ri` 用于解释“这个分项让大盘相对基准变化了多少”。例如 `Ri = 0.03`，表示该分项单独让总体较基准增加 3%。

### 一般线性形式

若：

```text
Y = Σ ai * Xi
```

其中 `ai` 是固定系数，则：

```text
ΔY = Σ ai * ΔXi
Vi = ai * ΔXi
Ci = Vi / ΔY
Ri = Vi / Y0
```

适用于“价格固定、销量变化导致收入变化”这类场景。若 `ai` 本身也变化，不要强行归入加法型，应拆成价格因子和销量因子，或使用乘法/定基代替。

### 计算步骤

1. 确认各分项互斥且加总等于总体。
2. 计算 `Y0`、`Y1`、`ΔY`。
3. 按维度计算 `Xi0`、`Xi1`、`ΔXi`。
4. 生成 `Vi`、`Ci`、`Ri`，并校验 `ΣVi = ΔY`。
5. 按 `abs(Vi)` 或 `abs(Ri)` 排序，输出 Top 驱动和抵消项。

### 推荐结果表

| 维度值 | 基准值 Xi0 | 当前值 Xi1 | 贡献量 Vi | 贡献率 Ci | 相对贡献 Ri | 解读 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| A |  |  |  |  |  | 解释/拉动/抵消 |

## 乘法型指标：LMDI / log 拆解

适用于 `GMV = UV * CVR * AOV`、`PV = UV * 人均PV` 等乘法链路。

### 基本形式

若：

```text
Y = Π Xi
```

取自然对数：

```text
ln(Y) = Σ ln(Xi)
Δln(Y) = ln(Y1) - ln(Y0)
Δln(Xi) = ln(Xi1) - ln(Xi0)
Ci_log = Δln(Xi) / Δln(Y)
```

`Ci_log` 表示第 i 个因子解释了对数变化的多少，所有因子的 `Ci_log` 理论上可加总为 100%。

如果需要把贡献换回原指标单位，可用对数平均权重：

```text
L(Y1, Y0) = (Y1 - Y0) / (ln(Y1) - ln(Y0))
Vi ≈ L(Y1, Y0) * Δln(Xi)
Ci = Vi / ΔY
Ri = Vi / Y0
```

当 `Y1 = Y0` 时，贡献率分母为 0，不应输出 `Ci`；改输出各因子的方向和对数变化，或换比较窗口。

### 计算步骤

1. 写出业务链路公式，例如 `GMV = UV * CVR * AOV`。
2. 确认 `Y` 和所有 `Xi` 都为正数；零值、负值不能直接取 log。
3. 计算 `Δln(Y)` 与各 `Δln(Xi)`。
4. 计算 `Ci_log`，并检查 `ΣΔln(Xi) = Δln(Y)`。
5. 如需要业务量级解释，再用 `Vi ≈ L(Y1,Y0)*Δln(Xi)` 还原影响量。

### 解读口径

- `Δln(Xi) > 0` 且 `Δln(Y) > 0`：该因子拉动增长。
- `Δln(Xi) < 0` 且 `Δln(Y) > 0`：该因子抵消增长。
- `Ci_log` 可超过 100%，表示该因子贡献超过总变化，其他因子在反向抵消。
- log 拆解适合指标变化不极端的情况；从很小数到很大数的跨量级变化会放大不稳定性。

## 乘法或多因素共同作用：Shapley

当多个因素存在交互，且“先替换哪个因子”会影响贡献分摊时，使用 Shapley 思路。

定义因素集合 `N`，价值函数 `v(S)` 表示因素子集 `S` 生效时的指标值或增量，则因素 `i` 的 Shapley 值为：

```text
φi = Σ [ |S|! * (n-|S|-1)! / n! ] * [ v(S ∪ {i}) - v(S) ]
     S⊆N\{i}
```

含义：在所有可能加入顺序下，计算因素 `i` 加入前后的边际增量，并取加权平均。

使用条件：

- 有实验、模型或历史数据能估计 `v(S)`。
- 因素数量不要太多，否则组合数爆炸。
- 若业务顺序不是随机的，应调整排列权重，不要默认所有顺序等概率。

## 比率型指标：组间组内拆解

适用于转化率、支付成功率、投诉率、退款率等 `Y = P / Q` 指标。

### 加权平均表达

把总体 `G` 拆成互斥分组 `Gi`：

```text
Yi0 = Pi0 / Qi0
Yi1 = Pi1 / Qi1
wi0 = Qi0 / Q0
wi1 = Qi1 / Q1
Y0 = Σ wi0 * Yi0
Y1 = Σ wi1 * Yi1
ΔY = Y1 - Y0
```

其中 `Yi` 是分组内率值，`wi` 是分组占比。总体率值变化来自两类力量：

- **组内贡献**：同一分组自身率值变化。
- **结构贡献**：分组占比变化，也就是 mix shift。
- **交叉项**：率值和占比同时变化的交互影响。

### 基期权重拆解

这是最常用、直观的一版：

```text
组内贡献 Wi = wi0 * (Yi1 - Yi0)
结构贡献 Bi = (wi1 - wi0) * (Yi0 - Y0)
交叉贡献 Ii = (wi1 - wi0) * (Yi1 - Yi0)
总贡献 Vi = Wi + Bi + Ii
Ci = Vi / ΔY
Ri = Vi / Y0
```

校验：

```text
ΣWi + ΣBi + ΣIi = ΔY
Σ(wi1 - wi0) = 0
```

`Bi` 使用 `(Yi0 - Y0)`，是为了表达“某类人群占比变化时，它相对大盘基准率更高还是更低”。如果低于大盘的群体占比提升，通常会拉低总体率值，即结构贡献为负。

### 当前期权重拆解

也可用当前期视角：

```text
组内贡献 Wi' = wi1 * (Yi1 - Yi0)
结构贡献 Bi' = (wi1 - wi0) * (Yi0 - Y0)
总贡献近似 Vi' = Wi' + Bi'
```

两种视角都可用。默认优先用“基期权重 + 交叉项”，因为它更容易解释“如果结构不变，仅分组表现变化会怎样”。

### 计算步骤

1. 先按分组计算分子 `P`、分母 `Q`、率值 `Y`。
2. 计算分组占比 `wi = Qi / Q`。
3. 计算组内、结构、交叉贡献。
4. 校验贡献加总是否等于 `ΔY`。
5. 输出分组维度的 `Vi`、`Ci`、`Ri`，并标注贡献来自表现变化还是结构变化。

### 解读口径

- 若各分组率值都上升但总体下降，优先解释结构贡献，常见于低率值群体占比上升。
- 若总体上升但结构贡献为负，说明结构在拖累，真正拉动来自组内表现改善。
- 比率型指标不能只用“分组率值变化 / 总体率值变化”计算贡献，否则可能不加总、也容易误判辛普森悖论。

## 链式拆解：漏斗和路径指标

适用于注册、下单、支付、审批等多阶段链路。若：

```text
R = 支付 / 访客
R = (浏览 / 访客) * (加购 / 浏览) * (下单 / 加购) * (支付 / 下单)
```

则把每个环节转化率作为乘法因子，优先用 LMDI / log 拆解计算每个节点对总体转化变化的贡献。

步骤：

1. 列出完整链路，确认节点口径和去重口径一致。
2. 计算每个节点的当前值、基准值、转化率。
3. 用 log 拆解识别贡献最大的断点。
4. 对关键断点继续按端、渠道、版本、人群、区域下钻。

## 非线性指标：泰勒展开和定基代替

当指标是非线性函数：

```text
Y = f(X1, X2, ..., Xn)
```

若因子变化不大，可用一阶泰勒近似：

```text
ΔY ≈ Σ (∂f/∂Xi | 基准点) * ΔXi
Vi = (∂f/∂Xi | 基准点) * ΔXi
Ci = Vi / ΔY
Ri = Vi / Y0
```

若业务更需要直观解释，可用定基代替：

```text
Vi = f(X10, ..., Xi1, ..., Xn0) - f(X10, ..., Xi0, ..., Xn0)
```

定基代替的贡献通常不能完全加总到 `ΔY`，因为存在交互项。输出时必须列出残差：

```text
残差 = ΔY - ΣVi
```

## 帕累托排序

用于快速锁定优先级：

1. 对 `Vi` 或 `Ri` 取绝对值排序。
2. 计算累计贡献占比。
3. 优先解释累计贡献达到 70%-90% 的少数分项。
4. 对剩余长尾只汇总说明，不逐项讲故事。

帕累托只能说明优先级，不能证明因果。

## 输出要求

贡献度分析至少给出：

```text
总变化 ΔY
总体相对变化 g = ΔY / Y0
Top 分项贡献量 Vi
Top 分项贡献率 Ci = Vi / ΔY
Top 分项相对贡献 Ri = Vi / Y0
正向拉动项、反向抵消项、未解释残差
```

推荐一句话：

```text
本期 Y 较基准期变化 ΔY，变化率 g。A 分项贡献 Vi，解释了 Ci 的总变化，相当于让总体相对基准变化 Ri；B 分项反向抵消了 ...；剩余残差为 ...
```

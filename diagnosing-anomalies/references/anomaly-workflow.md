# 异动诊断工作流

## 判断是不是异动

先把“异常”转成可检验问题：

- 当前窗口：发生异动的日期、周、月、小时或版本区间。
- 基准窗口：上期、上周同期、去年同期、滚动均值、模型预测值或实验对照组。
- 变化量：当前值 - 基准值。
- 变化率：变化量 / 基准值。
- 显著性：是否超过正常波动范围，是否持续，是否影响核心业务。

不要只看百分比。小基数的大幅变化可能不可行动，大基数的小幅变化也可能重要。

## 常见异动形态

| 形态 | 判断重点 | 常见原因 |
| --- | --- | --- |
| 单点尖峰/尖谷 | 是否补数、重复、单日事件、监控误报 | 埋点异常、活动爆发、外部突发 |
| 阶跃变化 | 起点是否清晰，之后是否维持新水平 | 版本发布、策略切换、口径变更 |
| 持续漂移 | 斜率、持续时长、是否跨周期 | 用户结构变化、供给变化、渠道质量衰减 |
| 周期性波动 | 是否符合周/月/节假日规律 | 工作日效应、季节性、预算节奏 |
| 分段恢复 | 何时开始、何时恢复、恢复前后是否同口径 | 故障修复、补数完成、回滚生效 |

## 基准选择

- 有强周期：优先用上周同期、去年同期、同工作日或周期模型。
- 有趋势：用趋势调整后的预测基线，避免把自然增长误判为异动。
- 活动或发布：用活动前稳定期、灰度对照组或未受影响人群。
- 数据未完整：等待完整周期，或只比较同等完整度的窗口。

## 异动确认清单

- 当前值、基准值、绝对变化、相对变化已复现。
- 当前窗口和基准窗口的粒度一致。
- 周期性、节假日、活动日已处理或说明。
- 数据新鲜度和补数状态已确认。
- 异动规模足以值得归因，或用户明确要求排查。

# 多因素共同作用：Shapley

用于多个因素同时作用且存在交互的场景，例如多个运营活动、推荐位、优惠策略共同影响 GMV 或转化。

## 原理

定义因素集合 `N`，价值函数 `v(S)` 表示因素子集 `S` 生效时的指标值或增量。因素 `i` 的 Shapley 值为：

```text
φi = Σ [ |S|! * (n-|S|-1)! / n! ] * [ v(S ∪ {i}) - v(S) ]
     S⊆N\{i}
```

含义：在所有可能加入顺序下，计算因素 `i` 加入前后的边际增量，并取加权平均。

## 怎么计算

当前没有通用脚本，因为 Shapley 需要 `v(S)`，通常来自正交实验、AB 实验、模型反事实或可靠业务规则。

最小输入表应包含：

| 因素组合 S | 指标值或增量 v(S) |
| --- | ---: |
| 空集 |  |
| A |  |
| B |  |
| A+B |  |

## 输出重点

```text
φi：因素 i 的平均边际贡献
贡献率：φi / Σφi
成本可得时：ROI = φi / 成本
```

## 使用边界

- 因素数量不要太多，否则组合数爆炸。
- 如果业务触达顺序不是随机的，应调整排列权重，不要默认所有顺序等概率。
- 没有可靠 `v(S)` 时，不要强行做 Shapley；先改用贡献度拆解或实验设计建议。

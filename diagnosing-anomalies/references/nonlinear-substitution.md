# 非线性指标：泰勒展开和定基替代

用于 `Y = f(X1, X2, ..., Xn)` 这类无法直接归为加法、乘法或比率型的复杂公式，例如 ROI、综合评分、带约束的收益指标。

## 泰勒展开

当因子变化不大，可用一阶泰勒近似：

```text
ΔY ≈ Σ (∂f/∂Xi | 基准点) * ΔXi
Vi = (∂f/∂Xi | 基准点) * ΔXi
Ci = Vi / ΔY
Ri = Vi / Y0
```

适合公式明确、能计算偏导、变化幅度不大的场景。

## 定基替代

固定其他因素为基准期，只替换某个因素：

```text
Vi = f(X10, ..., Xi1, ..., Xn0) - f(X10, ..., Xi0, ..., Xn0)
```

这更直观，但通常存在交互残差：

```text
残差 = ΔY - ΣVi
```

## 怎么计算

当前没有通用脚本，因为需要用户给出明确公式 `f()`。最小输入应包含：

| 因子 | 基准值 Xi0 | 当前值 Xi1 | 业务含义 |
| --- | ---: | ---: | --- |

以及完整指标公式。

## 输出重点

- 每个因子的 `Vi/Ci/Ri`。
- 残差大小和处理方式：单列“交互/残差”，或按贡献权重分摊。
- 哪些因子是正向拉动，哪些因子是反向拖累。

## 使用边界

- 因子变化很大时，一阶泰勒可能不可靠。
- 定基替代受替换顺序影响；若顺序影响很大，应考虑 Shapley。

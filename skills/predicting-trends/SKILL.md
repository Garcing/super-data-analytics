# 业务趋势预测

回答“在明确假设下，未来可能落在哪个范围”。预测值不是目标值；结果必须带方法、回测、合理区间、假设、风险和置信度。

## 核心原则

- 先复现历史指标和口径，再做未来判断。
- 先建立简单基线并回测，再考虑趋势模型。
- 简单、稳定、可解释的方法优先于轻微更准的复杂外推。
- 结构断点或未来依赖未知动作时，用场景分析，不给伪精确点预测。
- 预测与目标分开表达。

## 默认流程

### 1. 明确问题

确认指标定义、预测窗口、历史窗口、时间粒度、业务范围、用途和交付形式。目标类问题还要确认是保守/基准/挑战目标，还是判断既有目标能否达成。

受治理指标先用 retrieving-context 对齐口径，再由 `sql_query` 聚合连续的 `date + value` 序列。

### 2. 检查历史可用性

- 最新周期是否完整；进行中的周/月不能当完整点。
- 口径、采集、ETL、过滤和时间粒度是否稳定。
- 是否缺期、重复日期、非数值、补数、截断或极端值。
- 是否有大促、投放、价格、供给、政策、版本发布等结构变化。
- 历史是否覆盖与预测窗口可比的季节周期。
- horizon 是否相对历史长度过长。

最新值疑似异常时先用 diagnosing-anomalies。断点前后机制不同则只用断点后数据，或分别做场景；不要机械拼接。

### 3. 建立基线

先比较：最近一期、近期移动平均、上一季节同周期、近期 run rate。没有证据表明复杂趋势更可靠时，保留简单基线。

### 4. 选择模型

| 场景 | forecast model |
|---|---|
| 历史短或波动大 | `naive` / `moving_average` |
| 近期水平更重要 | `weighted_moving_average` |
| 水平稳定、噪声为主 | `exponential_smoothing` |
| 稳定加法趋势 | `holt_linear` / `linear_trend` |
| 正值且增长率稳定 | `log_linear_trend` |
| 季节性主导且至少两个完整周期 | `seasonal_naive` + `season_length` |
| 无法预先判断 | `auto_baseline` |

模型参数和 payload 字段以 `forecast` 工具输入 schema 为准。关键约束：序列至少 2 点且日期不重复；`holt_linear` 至少 3 点；log-linear 全部值大于 0；seasonal naive 需要足够完整周期。

需要复杂模型或专项建模的信号：多重季节性、已知未来驱动变量、高影响长期预测、强自相关、分群机制差异大，或问题实际要求因果预测。此时轻量 `forecast` 只作基线。

### 5. 回测与选型

历史足够时必须留出最近若干期回测。按以下顺序解读：

1. `warnings`：任何警告都要进入结论，不能隐藏。
2. `backtest`：MAE 看原单位误差，MAPE 看相对误差（真实值为 0 时不适用），RMSE 对大误差更敏感。
3. `model_reason`：确认自动选型理由符合业务序列。
4. `confidence`：结合回测、历史长度、结构断点和未来不确定动作做最终分级。

当前实现可用经验标尺：MAPE ≤8% 通常较高，≤20% 中等，>20% 较低；这不是跨业务通用标准，应结合指标波动和决策容错。

模型误差接近时选择更稳定、可解释者，不因小数点后的差异换模型。

### 6. 表达不确定性

`forecast` 返回的 `lower/upper` 是基于残差的启发式业务范围，不是严格统计置信区间，也不会自动随 horizon 充分展宽。越远期越不确定，长周期必须额外说明。

置信度：

- 高：历史充足可比、回测误差低、无已知断点。
- 中：历史可用但有波动或业务假设风险。
- 低：历史短、警告存在、误差高、口径不稳或未来主要依赖未知动作。

低置信度时减少小数精度，优先给保守/中性/激进场景。

### 7. 目标与达成判断

目标不是预测。三档目标：

- 保守：接近区间下沿或当前 run rate。
- 基准：接近点预测，代表当前条件延续。
- 挑战：接近区间上沿或点预测加计划增量，必须说明抓手与资源。

判断目标能否达成时传 `target`，并补算剩余目标、剩余周期、所需 run rate、历史/预测 run rate 和历史峰值。输出“大概率可达/有风险可追回/无额外抓手较难/暂无法判断”。详见 [target-setting.md](references/target-setting.md)。

## 输出模板

```text
预测结论：预计 <指标> 在 <窗口> 为 <点值>，合理范围 <下限–上限>。
依据：使用 <历史窗口/粒度>，模型 <名称>；回测 MAE/MAPE/RMSE 为 <值>。
关键假设：<口径稳定、周期完整、无重大动作变化>。
风险：<结构断点、季节性、资源约束、未来动作>。
置信度：<高/中/低>。
目标建议：<保守/基准/挑战>，挑战档需要 <抓手>。
下一步：<补数据、观察或业务动作>。
```

图表用 `chart` 展示历史实线、预测段、上下界和断点注释；不要把预测线画成已发生事实。

## 停止条件

- 历史太短，无法支撑预测窗口。
- 指标口径变化且无法统一。
- 最新周期不完整且无法合理折算。
- 已知结构变化使历史不可比。
- 未来主要由未知业务动作决定。
- 回测误差与区间宽度不足以支持用户决策。

此时说明最低可判断条件，或给基于明确假设的场景区间，不硬给单点。

## 常见陷阱

- 把活动增长当长期自然趋势。
- 因近期趋势强忽略季节性。
- 把半个月数据当整月。
- 只看总体而忽略业务结构变化。
- 用过多小数制造确定感。
- 把“预测总和”与“期末单期值”混淆；读取 `summary` 时明确字段语义。
- 隐藏 warnings 或只报模型名不报回测。

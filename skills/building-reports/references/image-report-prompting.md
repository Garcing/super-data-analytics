# Seedream 图片报告提示词写法（report_image_generate）

真相源：`sda_mcp/skills/building_reports/image_gen.py`。provider 为火山方舟 Seedream，默认模型由服务端 config 的 `VOLCENGINE_ARK_IMAGE_MODEL` 决定，也可通过 `model` 入参覆盖；调用是**同步单次 HTTP、无 task 轮询**。

## 运行边界

- `size=2K` + prompt 写「3:4」可作为竖版报告的常用起点；实际像素以模型返回为准。
- 生图通常明显慢于普通工具调用，耗时受模型和负载影响；未得到明确失败前不要重复提交。
- 中文和数字可能生成正确，也可能出现错字、漏字或数值变形；完整提供数据只能降低风险，不能替代逐项验收。
- 返回 TOS 签名 URL 带 `X-Tos-Expires=86400`（24h），不上传 Blob。

## 提示词结构（照填）

Seedream 不会自己脑补数据，把以下信息全部写进 prompt：

1. **图片类型 + 比例声明**（比例必须写进 prompt，不能只靠 `size` 传分辨率）：
   - 数据海报/单图播报：「生成一张 3:4 竖版数据播报信息图」
   - 周报头图/封面：「生成一张 16:9 横版周报头图」
2. **【主题】**：什么报告、给谁看、什么场合。如「给运营周会看的 GMV 周报简报，业务负责人 10 秒定位问题」。
3. **【关键数字】**：真实数值原样写全——KPI、分项、环比。**数字要写全**（1280 万、+11.3%），不要写「见数据」让模型编。
4. **【趋势结论】**：时间序列逐点列出（如「近 8 周：820,910,980,1020,1100,1080,1150,1280」），加 2-4 条结论并标出要高亮的。
5. **【版式与风格】**：区块布局（顶部标题+KPI 卡 / 中部图表 / 底部结论卡）、配色、留白、中英文。

## 模板

```
生成一张 <3:4 竖版|16:9 横版><数据海报|周报头图|单图播报>。
【主题】<一句话：什么报告、给谁、什么场合>
【关键数字】<KPI + 分项 + 环比，写全>
【趋势结论】<时间序列逐点 + 2-4 条结论，标出高亮项>
【版式与风格】<区块布局 / 配色 / 留白 / 中文 / 数字粗体>
【强制规则】所有图表必须带数据标签（每个柱/点旁标具体数值）；数值须与提供数据完全一致，不得编造；不画未指定的图。
```

## 关键纪律

- **所有图表必须带数据标签**：生图模型的坐标轴/比例不保证精确，读者凭柱高估读会被误导；把准确数值直接标在图上是唯一可靠兜底。
- **数值不得编造/失真四舍五入**：prompt 里给什么就要求渲染什么。
- **比例写进 prompt**：「3:4 竖版」「16:9 横版」这些字样要出现在文本里，`size` 参数只控分辨率档位（如 `2K`）。

## 负面边界（什么时候不该用它）

- **不要用它替代 `chart` 画精确数据图**：柱高/折线位置/扇区角度都可能有视觉偏差；要数值精确、可复现的图表走 visualizing-data 的 `chart`。image 报告适合「一图播报结论」，精确图表作为独立交付物时用 chart 出图再引用其 URL。
- 数据量大、要多图钻取、要交互 → HTML 报告（`report_html_publish`）。
- 需要多张候选图/批量组图 → 不支持（首版固定非流式单图语义，不发送 stream/组图字段）。

## 参数速查

| 参数 | 说明 |
|---|---|
| `size` | `"2K"` 或模型支持的 WxH；报告类建议 2K 保证文字清晰 |
| `response_format` | `url`（默认，返回 24h 下载链接，适合转述/留存）/ `b64_json`（返回 MCP 图片块，适合直接给用户看图） |
| `seed` | -1..2^31-1；固定 seed 可提高近似复现性，但不保证像确定性图表那样逐像素一致 |
| `watermark` | 默认 false |
| `model` | Model ID 或 Endpoint ID；缺省 config `VOLCENGINE_ARK_IMAGE_MODEL` |

## 生成后检查清单

- [ ] 图上数值与提供数据**逐个核对**；任何错字、漏字或数字变形都不能交付。
- [ ] 每个图表都带数据标签。
- [ ] 结论文字无错别字。
- [ ] **需要留存的立即下载**：URL 24h 过期（`X-Tos-Expires=86400`），服务端不落盘、不上传 Blob；错过时效只能带原 seed 重生成（近似复现）。
- [ ] 失败/超时不会自动重试（防重复计费），确认报错原因（401/403 key 无效、429 限流）后再手动重试。
